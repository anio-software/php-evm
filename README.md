# 🐘 EVM - Easy Virtual Manual

EVM is a small library that makes it easy to access the official PHP manual programmatically.
EVM provides an object-oriented API for navigating the PHP manual and inspecting definitions, parameters, and types.

> [!IMPORTANT]
> All ongoing development and work in progress is available in the [**`dev`**](https://github.com/anio-software/php-evm/tree/dev) branch.
>
> The **`main`** branch is currently empty, as no stable version of the project exists yet.
>
> Please note that the [**`dev`**](https://github.com/anio-software/php-evm/tree/dev) branch may contain unfinished features, breaking changes, and experimental code.
